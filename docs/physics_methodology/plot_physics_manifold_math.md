# Phase Manifold Visualizations

Before machine-learning training, the visualization suite in `src/visualize/` plots projections
of the synthetic sequences generated by the TOV solver.

The framework produces several key projections:
- **The $M-R$ Plane:** This illustrates the mass-radius relationship. Plotting many generated
  curves makes model-specific shapes and overlap visible inside the sampled design.
- **The $M-\Lambda$ Plane:** This charts the steep inverse scaling of the tidal deformability $\Lambda$ against the stellar mass $M$, highlighting how rapidly finite-size effects vanish as the star approaches the Buchdahl limit.

These projections are diagnostic checks for numerical pathologies, unexpected shapes, and class
overlap before ingestion. They do not independently validate the repository APR-1 surrogate, the
analytic CFL MIT-bag model, or the physical representativeness of the generated population.
